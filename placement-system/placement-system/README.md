# CampusHire – Student & Placement Management System
Node.js + Express + MongoDB (Mongoose) + vanilla JS frontend.

## Run
1. Install Node 18+ and MongoDB (or create a free MongoDB Atlas cluster).
2. `cp .env.example .env` and set `MONGO_URI` (Atlas string or local).
3. `npm install`
4. `npm start` → open http://localhost:3000

Students register themselves on the login screen. Administrative and recruiter accounts are seeded internally for authorized use only.
